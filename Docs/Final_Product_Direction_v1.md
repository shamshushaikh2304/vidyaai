# AryaLearn Final Product Direction

AryaLearn is Netflix for Education.

Student Experience:
- Continue Learning
- Today's Lineup
- Browse Subjects
- Shows
- Seasons
- Episodes
- Story Based Learning

Parent Experience:
- Board
- Class
- Subject
- Curriculum Mapping
- Progress Tracking

Learning Formula:

Story
→ Explanation
→ Practice
→ Quiz
→ Next Episode

Not:

Video
→ Quiz

MVP Focus:

1. Student Home
2. Show Detail
3. Episode Page
4. Parent Curriculum Browser

No AI Video Generation in MVP.
No Teacher Portal.
No School Dashboard.
